teacher side:
========== HOME VIEW ==========  
  Exam ongoing home view (statuses: PENDING, PUBLISHED, ONGOING — cannot edit if ONGOING):

    GET exams (includes: title, schedule, status, short description)
    GET exams by title (search bar)
    GET exams by status (ALL, PENDING, PUBLISHED)

    POST exam (default timer: "none")
    PATCH exam status (e.g. publish, cancel → pending)
    PATCH exam timer (set/edit timer)

    DELETE exam

    Future: Copy whole exam (prompt rename + change subjcode)

  Sidebar:
    GET teacher name

========== EXAM CREATION ==========  
  New / Editing Exam:

    POST exam (creates exam with default values)
    PATCH exam details (title, timer, schedule)

    GET exam_code (for display only)
    POST exam_code (if generating or customizing code)

    POST question (question_type, question_text, options a–d, correct_answer, points, created_at)
    PATCH question
    DELETE question

    POST section_takers (e.g., BSCS 1-A, BSIT 2-D)
    PATCH section_takers (add/remove sections)
    GET section_takers (view only)


========== EXAM ANALYTICS ==========
  Exam analytics Home view (for DONE exams only): 
  
    GET exams (title, schedule, description)
    GET exams by title (search bar)

  Inside the specific exam:

    GET questions (text, type, item_id, correct_answer)
    GET % of students (per section) who answered correctly

    GET essay answers (linked to essay-type questions)
    POST/GET/PATCH essay score (only visible if score exists)


  Per section view:

    GET student's section (from student before entering the exam)
    GET student name (fixed name in account creation)
    GET student total score

    GET student answers per question (optional; only if needed for review/audit)
